# project05
Kubernetes 없이 최소 비용으로 안정적인 서비스 운영하기

## 1. 프로젝트 소개
소규모 서비스를 대상으로 최소한의 인프라에서 시작하여 장애·트래픽·배포 문제를 검증하고, 필요한 기능을 단계적으로 추가하면서 비용 대비 운영 안정성을 확인/비교하는 인프라 프로젝트입니다.

## 2. 프로젝트 목표
최소 비용의 인프라에서 시작해 장애와 트래픽 증가를 직접 검증하고, 문제 해결에 필요한 인프라를 단계적으로 도입합니다.
이를 통하여 무조건적인 고가용성 구성이 아닌, 서비스 안정성과 운영 비용을 같이 고려하여 현재 서비스 규모에 적합한 인프라 구조를 설계하는 것을 목표로 합니다.
